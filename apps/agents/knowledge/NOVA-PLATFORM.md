# Nova — Agent Knowledge Base

## Product Overview

Nova is a commercial growth SaaS for Venezuelan merchants. Catalog, payments, CRM, and AI agents — all from the merchant's phone.

## Payment Methods

### Pago Movil
- Dominant payment system in Venezuela
- Requires: phone number, cedula (ID), bank name
- Instant transfers, 24/7
- Screenshots show: amount in Bs, reference number, bank, date/time

### Zelle
- Used for USD transactions
- Requires: email address
- Reference number format varies by bank

## Currency

- Dual pricing: USD + Bolivares (Bs/VES)
- Exchange rate: BCV official rate, updated every 15 minutes
- All internal calculations in USD, Bs shown for customer convenience

## Customer Segments (RFM)

| Segment | Description |
|---------|-------------|
| VIP | Buys often, spends a lot, recent |
| Loyal | Frequent buyer, recent |
| Potential Loyal | Recent, moderate frequency |
| At Risk | Used to buy, stopped |
| Hibernating | Low everything |
| New | First purchase, recent |
| One-Timer | Bought once, didn't return |
| Window Shopper | Visits but no purchases |
