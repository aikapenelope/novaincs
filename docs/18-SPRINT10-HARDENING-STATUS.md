# Nova — Sprint 10 Hardening Status

> **Status**: Active
> **Date**: May 2026
> **Scope**: Tracks what was fixed in Sprint 10 and what remains deferred for later phases.

## Fixed in Sprint 10

| # | Issue | What Changed |
|---|---|---|
| F1 | **RLS context leaked across pooled connections** | Changed `set_config('app.current_tenant', ..., true)` to `false` (session-level). Added `finally` block in `tenantMiddleware` and public checkout route to clear context after every request. Prevents tenant data leaking to the next request on the same pooled connection. |
| F2 | **Rate limiter in memory** | Replaced in-memory `Map` with Redis-backed rate limiter using `INCR` + `EXPIRE`. Survives container restarts, works across multiple instances. Falls back to in-memory in dev without Redis. |
| F3 | **No security headers** | Added `securityHeaders` middleware: `Strict-Transport-Security`, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`. |
| F4 | **CI typecheck silenced errors** | Removed `continue-on-error: true` from Dashboard and Catalog typecheck steps. Now filters only the known vue-router/volar plugin warning while failing on real type errors. |

## Deferred Items (Not Blocking Product Development)

These items are documented for future implementation. They are not blockers for beta or Sprint 10-15 product work.

### SSH Access (Audit A4)

**Decision**: SSH remains open to `0.0.0.0/0`.

**Reason**: SSH access is required for Neo (Pulumi AI agent) to inspect and manage the VPS. Restricting to specific IPs would break automated infrastructure management.

**Mitigations in place**:
- SSH password auth disabled (key-only)
- MaxAuthTries: 3
- fail2ban active (5 retries, 1h ban) — 71 IPs banned historically
- ED25519 key generated by Pulumi (not shared)

**Future**: When Tailscale ACLs are configured for the team, consider restricting SSH to Tailscale IPs + a CI/CD runner IP.

### Offsite Backups (Audit A5, Doc 16 H7)

**Current state**: `pg_dump` runs daily at 3:00 AM, stored at `/var/lib/nova/backups/` on the same server.

**Risk**: Server loss = data loss + backup loss.

**Plan**: Before paid launch (Sprint 15), add `rclone` sync to Cloudflare R2 after each backup. Estimated cost: $0.08/mo for ~5GB.

### Coolify Panel Public (Audit A9)

**Current state**: `deploy.martes.app` is publicly accessible with Coolify login.

**Decision**: Keeping it public for now. Coolify has its own auth.

**Mitigations**: Also accessible via Tailscale at `http://100.123.199.40:8000`. Prefer Tailscale for admin access when possible.

**Future**: Consider Cloudflare Access or removing the public Traefik route before paid launch.

### Observability (Audit A12, Doc 16 H1-H6)

**Current state**: No Sentry, no Prometheus/Grafana, no alerting, no structured logging.

**Plan**: Implement in phases:
- Sprint 12 (agents): Sentry free tier (5K events/mo) for error tracking
- Sprint 15 (paid launch): UptimeRobot for basic uptime alerts
- After 100 merchants: Grafana + Loki + Prometheus self-hosted (~300MB RAM)

### Staging Environment (Audit A10, Doc 16 H21)

**Current state**: All deploys go directly to production.

**Plan**: Before paid launch (Sprint 15), set up a second Hetzner CX22 (~EUR4/mo) or local Docker Compose mirror.
